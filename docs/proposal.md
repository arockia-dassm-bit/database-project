# Clinic Appointment Database

## Problem Description

A clinic needs to keep track of patients, doctors, and appointments. Managing this information manually can make it difficult to know when appointments are scheduled, which doctor is seeing a patient, and which appointments have been completed or canceled.

The database will organize clinic information in one place and make it easier to manage appointments.

## Purpose of the Database

The purpose of this database is to store and manage information about patients, doctors, and clinic appointments. It will help clinic staff organize appointments and quickly find important information.

## Intended Users

The intended users of the database are:

- Clinic receptionists
- Doctors
- Nurses
- Clinic administrators

## Major Data That Must Be Stored

The database will store:

- Patient information
- Doctor information
- Appointment information
- Appointment dates and times
- Appointment status
- Doctor specialties
- Patient contact information
- Appointment notes

## Questions the Database Should Eventually Answer

1. What appointments are scheduled for a specific day?
2. Which doctor is assigned to a specific appointment?
3. Which patients have appointments with a specific doctor?
4. What appointments have been canceled?
5. How many appointments does each doctor have?
6. What is the appointment history of a specific patient?
7. Which doctors specialize in a specific medical area?

## Initial Business Rules

1. Each patient can have multiple appointments.
2. Each appointment must belong to one patient.
3. Each appointment must be assigned to one doctor.
4. A doctor can have multiple appointments.
5. Each appointment must have a date and time.
6. Each appointment must have a status, such as scheduled, completed, or canceled.
7. Patient contact information must be stored so the clinic can contact the patient.
